### PLUGIN — Why use SDLore?

SDLore lets you manage item lore, names, and enchantments directly from a web interface, without needing to recompile or restart your server. This enables faster updates, centralized control, and a much more dynamic experience for servers aiming for advanced customization.

---

### FEATURE — Web-Based Item Management

Manage item names, lore, and enchantments through a web platform connected to an API, without editing files or recompiling the plugin. Keep everything organized, scalable, and easy to maintain.

---

### FEATURE — API-Driven Sync

The plugin fetches and applies data directly from the API, ensuring all items stay up to date automatically with full in-game consistency.

---

### FEATURE — Hot Reload

Make changes to your items and apply them instantly in-game without restarting or fully reloading the plugin. Perfect for rapid testing, gameplay balancing, or dynamic events where immediate updates are essential.

---

### SHOWCASE — SDLore Editor

*Create spectacular lores for your Minecraft items.*

The built-in editor supports MiniMessage formatting, real-time lore preview, and enchantment management — all from a clean web UI.

## 🛠️ SDLore Editor

The editor provides a rich web UI to craft item metadata using MiniMessage format:

- **Item Name** — styled with MiniMessage *(and Legacy)* color tags
- **Lore Lines** — add, reorder, and remove lines with live preview
- **Enchantments** — manage enchantment entries directly from the panel
- **Flags** — manage item flags entries directly from the panel
- **Game-like preview** — preview the item name and lore from the editor
- **Generate Code** — export ready-to-use configuration
